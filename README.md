# CSE2004 Web Development

Consolidated web development coursework — HTML/CSS/JS pages and sites in one place.

## Contents

| Folder | What it is | Originally |
|---|---|---|
| `website1-bass-fishing/` | **Bass Fishing for Beginners** — a personal bass-fishing companion site: beginner guide, lure picker, seasonal patterns, St. Louis-area waters, trip checklist, trip planner, and a catch log (all client-side, localStorage) | `website1-bass-fishing` |
| `website2-forest-park/` | **Forest Park field notes** — a hand-painted field guide to fourteen Forest Park places with a weather-aware outing planner (Open-Meteo forecast API + Web Storage + Intersection Observer + Blob/Object URL export); the site itself lives in `dist/` | Website #2 assignment |
| `class-survey-charts/` | Class survey results charted with Chart.js (single self-contained page) | `class-survey-charts` |
